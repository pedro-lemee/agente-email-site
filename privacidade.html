Política de Privacidade — Agente Email

Última atualização: 06/10/2026

Quem usa

O Agente Email é uma ferramenta pessoal. Ele acessa apenas as contas Gmail do próprio desenvolvedor, que as autorizou explicitamente, e não é oferecido a outras pessoas.

Dados acessados

  • Leitura de e-mails (gmail.readonly): remetente, assunto, data e texto dos e-mails recebidos nas últimas 24 horas.
  • Envio de e-mail (gmail.send, só na conta pessoal): usado exclusivamente para enviar o resumo diário para o próprio usuário.

Como os dados são usados

O conteúdo dos e-mails é usado apenas para classificá-los por prioridade e gerar o resumo diário. Para a classificação, o texto é processado pelo Claude (Anthropic) por meio da assinatura do próprio usuário. O aplicativo não envia e-mails a terceiros, não modifica nem apaga mensagens e não guarda cópias dos e-mails: os dados existem só durante a execução diária.

Compartilhamento

Os dados não são vendidos, compartilhados nem usados para publicidade. O uso das informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
